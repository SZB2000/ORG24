# 跟弹曲库

当前测试曲目：阿杜《离别》主歌开头两小节，共 16 次按键。

依据用户提供的《离别_阿杜.pdf》第 1 页人工核对，采用谱面 Am 调（1=C），保留高音点；连音合并为一次按键，休止跳过，不考核时值或节拍。本版本不含伴奏控制，也不支持 PDF 自动识谱。

`catalog.json` 是应用启动跟弹曲库时读取的索引。每首歌曲包含 id、title、artist、url、size（UTF-8 字节数）、sha256。歌曲下载校验后存入应用本地，断网时可使用缓存。初始测试曲目也随 APK 附带。

曲目文件 schema=1，mode=wait-note；notes 为按顺序排列的单音事件，每项包含 midi（0–127 的绝对半音编号）和 label（给用户显示的谱面唱名）。本测试将中音 1 对应 MIDI 60，高音 1 对应 72。重复音必须松开再按，连音不重复列入。当前只支持单音跟弹。

新增曲目：先上传经过核对的曲目 JSON，再把其地址、字节数及 SHA-256 加到索引。应用重新打开跟弹曲库即可取得新列表；首次选择会下载，之后可离线练习。尚未实现的伴奏/按钮动作暂保留为空的 actions，不会执行。
