# 跟弹教学

当前曲目：阿杜《离别》全谱旋律，依据用户提供的两页简谱人工转录，含前奏、主歌、副歌、间奏和尾奏，共 419 次按键。采用谱面 Am 调（1=C），音域 MIDI 57–88；保留高低音点和升音，连音合并为一次按键，休止不要求按键。不进行时值或节奏评分。

同一小节的目标键保持同色，小节间循环换色。琴键底部的 A–D 表示四拍，2/4 小节仅 A、B；当前音所在的拍突出显示。标记按练习进度推进，并非实时节拍器。开头弱起位于 D 拍。

自动音区默认开启；目标超出显示范围时，在手指松开后调整起始音，兼顾接下来几个音。退出教学恢复之前的键盘范围。

伴奏有关闭、手动、自动三档，默认关闭。手动模式可开始、停止并选择和弦；自动模式在按对第一个目标音时启动，随后随实际完成的音符换和弦。错误按键和手动浏览下一音不会触发自动伴奏。练习结束、关闭教学或应用进入后台时停止伴奏。

伴奏为 67 BPM 的轻鼓点、低音及分解和弦合成，用于练习，不是原曲录音，也不是原版 ORG 的某个节奏包。伴奏保持固定速度，旋律仍可等待；等待时保留当前和弦。不能视为严格的乐曲同步演奏。

## 曲库文件

`catalog.json` 是公开索引。`revision` 防止旧缓存覆盖新版随包目录。每首歌曲包含 id、title、artist、url、size（UTF-8 字节数）、sha256；下载地址固定到经校验的 Git 提交。曲目校验后缓存，断网时可使用缓存；《离别》也随 APK 附带。

曲目 schema=1、mode=wait-note；notes 按演奏顺序排列，每项包含 midi、label、bar、beat、meter、chord、section，以及原谱页码和行号。中音 1 对应 MIDI 60，高音 1 对应 72。bars 保存人工核对的分拍转录，+ 为高八度，- 为低八度，~ 为连音延续，0 为休止，_ 为延续拍；sections 保存各段入口。当前仅支持单音旋律，actions 留空。

新增曲目时先上传经过核对的曲目 JSON，再更新索引及校验值、递增 revision。首次选择新曲目会下载，之后可以离线练习。原两小节示例文件保留用于兼容，目录已切换至完整版本。
