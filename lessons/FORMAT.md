# 超级ORG 跟唱跟弹资源规范 v1

## 发布边界

只发布经过确认的曲目资料与资源包，不上传 APK、签名密钥、设备标识或开发日志。应用统一版本为 1.4，资源接口为 `org24-guitar-v1`。同接口的新曲目通过目录更新下载；新增不兼容的演奏功能时再升级应用。

## 每首曲目的制作顺序

1. 保存用户提供的完整谱面和参考录音/视频，在本地记录来源。逐页放大核对音高、八度、节奏、连音、休止与反复，不按录音长度猜测漏掉的音符。
2. 延音线连接的同音只发音一次，累加时值；没有延音线的同音保持两次触键。可弹奏的音符与是否显示歌词独立，隐藏“啦”字不得删除音符。
3. 逐音标注歌词起字、同字延长音或无歌词音。新字及同字延长音为橙色，无歌词音为黄色；空白歌词格不自动继承前字，必须核对谱面。
4. 为每句设置开始拍点。句内松手立即提示下一音，句间才等待节奏。连续同键次数在色框中央用黑色 ×2/×1；延音不算重复触键。
5. 伴奏按和弦分段切片，使用连续边界并检查前后串音。缓慢练习时延续当前段，用户准备好后切换，最后一段不无限重复。首和弦手动触发。
6. 记录 `engineConfig`：音色名称、键盘起始八度与偏移、白键数、和弦键绑定、采样率。当前接口支持 20–300 BPM、最多 9 个和弦绑定、22050 Hz 单声道有符号 16 位小端 PCM。
7. 校验源谱与全部可弹奏音符的顺序、音高和起拍，检查歌词覆盖两页/所有页。静态校验和编译不代替用户实际弹奏与试听。
8. 制作 ZIP 并计算文件大小与 SHA-256。先上传不可变的版本化资源包并验证公开下载，再更新目录。新曲目新增行；已有曲目更新时增加资源 revision，不能覆盖旧版本文件。

## GitHub 目录

- `lessons/catalog.json`：schema、目录 revision、songs 数组。
- 每个曲目项：id、title、artist、engine、revision、url、size、unpackedSize、sha256。
- Releases / `lessons-v1`：独立 ZIP 资源包。后续例如 `song-id-v2.zip`。
- `lessons/FORMAT.md`：本规范。

## ZIP 布局

- `manifest.json`：schema=1、engine、id、revision，以及 files 数组。每个文件都有 path、size、sha256。
- `song.json`：完整谱面、segments、lyric_lines 和 engineConfig。
- `guitar-loops/*.pcm`：由 segments.file 引用的伴奏切片；frames 必须与文件字节数/2一致。
- `source/score.pdf`：核对用原谱。
- `source/lyric-audit.json`：逐句逐音对应记录。

资源包只包含数据，不含可执行代码。下载先检查空间与整包哈希，解压限制在应用私有目录，逐文件校验后才标记可用。离线优先读取已下载曲目；第一首附带内置副本。云端目录连接失败时保留本地列表。不同曲目用独立 id 隔离；原始视频和制作中间文件留在本地，不混入运行时资源包。

## 当前第一首

《冬季到台北来看雨》，歌手展示孟庭苇，参考编配沈以诚。35 小节、128 次可弹奏发音、11 处延音续接、64 段吉他音频。开头 16 个音仍需演奏但不显示“啦”字，预先显示第一句正式歌词；“藏心底”后的高音 2、1 为无歌词音。保留相关用户确认后再改动。

## 改谱时的修订号

曲目 `revision` 是独立递增的正整数，与 APK 版本和目录总 revision 分开。当前曲目为第 1 版；下一次修谱使用第 2 版，目录中该曲目的 revision 与 ZIP 内 manifest.revision 必须一致。音符、歌词、和弦、节奏或切片任何一项修改都应升级曲目修订号。

打包当前曲目下一版使用 `package-lesson.py --revision 2`，随后运行 `publish-lesson.py`。发布工具拒绝倒退修订号、同号不同内容、覆盖旧资源文件以及误删其他曲目目录项。先保存并核验新 ZIP 的公开下载，再提高目录总 revision 发布目录。

应用打开曲目目录或点击刷新时检查更新。有本地/内置旧版且云端 revision 更高，垃圾桶变为回环更新按钮；用户可继续练习旧版。新资源校验完成后才启用新版并恢复垃圾桶。失败保留旧版。删除操作清理该曲目的所有已下载修订版，不删除 APK 内置副本。

## 快速音组的深浅预告

当前音、下一音、再下一音分别使用 245/255、112/255、36/255 的不透明度，边框同步变淡。每个音继续按自己的歌词归属使用橙色或黄色；不跨休止或下一句提前提示，也不改变音符数量与时值。相同琴键重按仍用 ×2/×1，不把两个同音框叠加。延音续接已合并为一次发音，不当作新的按键。

现有资源可直接使用 `slurs` 及同拍内连续短音分组。普通八分、十六分音符组不能误称为三连音。后续谱子可显式提供 `preview_groups`，每项含 `start: [小节,拍位]`、`end: [小节,拍位]`、`kind: "tuplet"` 或 `"legato"`；真实时值仍由 notes 决定。发布之前对照全部 PDF 页面核对这些标记。
